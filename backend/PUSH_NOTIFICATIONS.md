# Push-сповіщення: готова основа

Сервер уже:

1. перевіряє офіційне джерело тривог раз на заданий інтервал;
2. записує лише зміну стану «тривога» / «відбій»;
3. має таблицю підписок пристроїв і API `POST /api/notifications/subscriptions`;
4. надсилає повідомлення до Expo Push Service тільки якщо `EXPO_PUSH_ENABLED=true`.

За замовчуванням надсилання вимкнено — це захищає від помилкових або тестових повідомлень.

## Що ще потрібне для реальної доставки на телефон

- встановити `expo-notifications` у мобільному клієнті;
- отримати дозвіл користувача та Expo Push Token на фізичному телефоні;
- підключити Apple Push Notification service для iOS та Firebase Cloud Messaging для Android у EAS/Expo;
- протестувати «тривогу» і «відбій» на тестовому пристрої;
- тільки після цього увімкнути `EXPO_PUSH_ENABLED=true`.

Для зустрічі з містом це чесна демонстрація: уже є джерело, фіксація переходу стану, налаштування користувача, база підписок та безпечно вимкнений канал доставки. Місто або IT-кластер можуть допомогти з обліковими записами Apple/Firebase, офіційним джерелом і правилами відповідального надсилання.
