# Укриття та пункти незламності

Усі точки, які команда додає або виправляє вручну, лежать у файлі
`src/main/resources/safety-map-points.json`. Java-код для цього редагувати не потрібно.

## Як додати точку

1. Відкрийте `safety-map-points.json`.
2. Вставте об’єкт у масив `shelters` для укриття або `resilience` для пункту незламності.
3. Заповніть назву, повну адресу та координати у форматі десяткових чисел.
4. Змініть `updatedAt` на поточні дату й час у форматі UTC, наприклад `2026-10-01T14:30:00Z`.
5. Перезапустіть бекенд. Після цього оновіть застосунок.

Приклад одного укриття:

```json
{
  "id": "shelter-rakoczi-2",
  "name": "Укриття — Центр «Совине гніздо»",
  "address": "вул. Ференца Ракоці, 2, Ужгород",
  "latitude": 48.624859,
  "longitude": 22.294771
}
```

Приклад файлу з однією точкою:

```json
{
  "updatedAt": "2026-10-01T14:30:00Z",
  "shelters": [
    {
      "id": "shelter-rakoczi-2",
      "name": "Укриття — Центр «Совине гніздо»",
      "address": "вул. Ференца Ракоці, 2, Ужгород",
      "latitude": 48.624859,
      "longitude": 22.294771
    }
  ],
  "resilience": []
}
```

Для пункту незламності структура така сама; змінюється лише масив на `resilience`.
Координати можна взяти з Google Maps: натиснути правою кнопкою або довго натиснути
на місце й скопіювати перші два числа. Дозволені лише точки в межах Ужгорода;
некоректні або порожні координати бекенд не покаже.

## Як працює об’єднання укриттів

Укриття з міського геопорталу підтягуються автоматично. Якщо вручну додана точка
має ті самі координати (з точністю приблизно 25 м) або той самий `id`, назва й адреса
з файла замінюють неповні дані геопорталу. Якщо такої точки на геопорталі немає,
вона все одно з’явиться на мапі як ручна перевірена точка.

Не додавайте адресу без перевірки з офіційним джерелом: у критичному сервісі
краще коротший, але точний перелік.
